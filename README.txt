축구팀 주장 수첩 (PWA)

[올리는 방법] 아래 중 하나면 돼요. 둘 다 무료이고, 설치형 앱은 https 주소에서만 동작해요.
1) Netlify Drop: app.netlify.com/drop 에 이 폴더(압축을 푼 captain-pwa 폴더)를 통째로 끌어다 놓으면 주소가 만들어져요.
2) GitHub Pages: 새 저장소에 이 폴더의 파일을 올리고 Settings > Pages 에서 켜면 주소가 만들어져요.

[팀원에게 알려줄 설치 방법]
- 안드로이드 Chrome: 주소를 열고 메뉴(점 3개) > 앱 설치 (또는 홈 화면에 추가)
- 아이폰 Safari: 주소를 열고 공유 버튼 > 홈 화면에 추가

[수정해서 다시 올릴 때]
sw.js 맨 위의 버전 숫자(captain-v19)를 올려서(captain-v20 ...) 올려야 팀원 폰에 새 버전이 반영돼요.
화면 구조는 index.html, 스타일은 styles.css, 앱 동작은 app.js에서 수정하면 돼요.
언어별 번역은 locales 폴더의 언어 파일에서 관리하며, 한국어를 포함해 선택한 언어 파일만 필요할 때 불러와요. 동적 문구는 `{count}` 같은 값을 포함한 템플릿으로 관리해요.
경기별 쿼터 수(1~20)와 각 쿼터 시간은 포메이션 탭에서 조정하고, 설정 탭의 기본 경기 설정은 새 경기에 적용돼요.

[데이터 안내]
데이터는 각자 폰의 브라우저에 따로 저장돼요. 팀원끼리 실시간으로 공유되지는 않아요.
주장이 설정 탭에서 백업 코드를 복사해 전달하면, 팀원은 설정 탭 가져오기로 같은 명단과 기록을 볼 수 있어요.
